# Community Contribution submission text

## Title
VEC MethodCard — machine-readable method, provenance and evidence record

## Description
VEC MethodCard turns reproducibility/disclosure notes into a structured JSON record that can be validated and rendered to Markdown. It records method/track, technical summary, preprocessing/training/generation details, explicit external-data statement, seeds, reproduction command, compute notes, Git/package environment, and exact artifacts with SHA-256 hashes. Agent-track validation additionally requires non-placeholder trajectory, prompts and harness evidence locations, reflecting the current prize-evidence requirements. The tool does not make eligibility judgments; it creates a portable, auditable method record that teams can keep beside submissions and update as methods evolve.
